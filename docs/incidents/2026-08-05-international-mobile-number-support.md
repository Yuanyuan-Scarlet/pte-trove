# 国际手机号无法领取买家资料

## 摘要

2026-08-04，澳大利亚买家反馈通过资料入口领取文件时无法使用澳大利亚本地手机号。2026-08-05 完成只读排查后确认：该行为是当前产品范围和实现共同造成的确定性限制，并非单个手机号格式异常或澳大利亚运营商的偶发故障。

当前系统从规格、前端输入、服务端校验到短信发送均只支持中国大陆 `+86` 手机号。要稳定服务澳大利亚、新西兰、加拿大等地的 PTE 备考中国学生，需要将手机号身份升级为 E.164 标准格式，按国家路由国内和国际短信接口，并完成目标国家要求的 Sender ID 或长码合规注册。

本文仅记录问题、证据和建议方案。业务代码、数据库和生产配置尚未修改。

## 用户可见现象

- 买家页面固定显示国家代码 `+86`。
- 输入框只允许 11 位数字，并要求符合中国大陆移动号段。
- 澳大利亚、新西兰和加拿大本地号码无法通过前端校验。
- 即使绕过前端提交，服务端仍会返回中国大陆手机号格式错误。
- 当前短信发送实现只调用国内短信接口，直接放开输入框仍无法形成可靠的国际短信链路。

## 根因与证据

根因已经确认，存在于以下完整链路：

1. [`SPEC.md`](../../SPEC.md) 将“国际手机号和国际短信”列为本期不包含范围，并明确要求中国大陆 `+86` 的 11 位手机号。
2. [`components/BuyerPortal.tsx`](../../components/BuyerPortal.tsx) 固定展示 `+86`，使用 `^1[3-9]\\d{9}$` 校验并限制输入长度为 11。
3. [`lib/constants.ts`](../../lib/constants.ts) 将手机号格式定义为中国大陆移动号段正则。
4. [`lib/domain.ts`](../../lib/domain.ts) 只处理 `+86` 前缀，并以中国大陆正则验证手机号。
5. [`lib/buyer.ts`](../../lib/buyer.ts) 在发送验证码和建立访问权限前再次拒绝非中国大陆手机号。
6. [`lib/sms.ts`](../../lib/sms.ts) 只调用阿里云国内 `SendSms` 接口及国内签名、模板配置。
7. 手机号同时参与 OTP 摘要、限流、买家绑定唯一约束、下载阶段重新验证、脱敏展示和 PDF 水印，因此不能只修改一个前端输入框。

## 阿里云能力与合规边界

阿里云中国站国际短信支持向全球多个国家和地区发送短信。国内短信与国际短信应作为两条独立发送链路处理：

- 中国大陆号码继续调用 `SendSms`。
- 澳大利亚、新西兰、加拿大号码调用 `SendMessageToGlobe`。
- 国际接口接收“国际区号 + 本地号码”，实现中应从 E.164 值移除开头的 `+` 后发送。
- 国际验证码应使用 `Type=OTP`，并设置与系统一致的 300 秒有效期。
- 国际短信接口受理成功不等于运营商最终送达，需要记录 Message ID 并补充送达状态观测。

官方资料：

- [调用 SendMessageToGlobe 发送国际短信](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2018-05-01-sendmessagetoglobe)
- [国际短信服务定价](https://help.aliyun.com/zh/sms/product-overview/pricing-of-messages-sent-to-countries-or-regions-outside-chinese-mainland/)
- [Sender ID 报备](https://help.aliyun.com/zh/sms/user-guide/senderid-report)

目标国家的已知要求：

### 澳大利亚

澳大利亚自 2026-07-01 起实施 SMS Sender ID 注册机制。未注册的字母数字 Sender ID 可能被替换为 `Unverified`，部分运营商可能进一步过滤或屏蔽。建议申请与企业名称、商标或 `ysspark.cn` 域名有明确关联的 ASCII Sender ID，并在生产发送前完成审核。

参考：[澳大利亚 SMS Sender ID 注册要求](https://help.aliyun.com/zh/sms/product-overview/australian-sms-compliance-requirements)

### 新西兰

使用新版国际短信控制台核对新西兰当前的 Sender ID 报备规则，并按控制台要求完成注册。国家规则和运营商要求可能变化，不能仅依赖代码中的静态假设。

### 加拿大

阿里云官方说明指出，发往加拿大的短信需要完成 TFN 或适用长码注册，否则送达率无法保障。正式启用加拿大前，应在国际短信控制台或工单中确认当前账号适用的号码类型、材料、审核时长和费用。

参考：[发往美国和加拿大短信的 TFN 注册说明](https://help.aliyun.com/zh/sms/product-overview/about-user-supplemental-registration-tfn-for-sms-sending-to-us-and-canada)

## 推荐技术方案

### 1. 统一手机号身份

支持国家先限定为以下白名单：

```text
CN  中国       +86
AU  澳大利亚   +61
NZ  新西兰     +64
CA  加拿大     +1
```

买家可以输入本地常用格式，服务端使用成熟号码库完成解析、国家校验、移动号码校验和 E.164 归一化。建议使用 `libphonenumber-js/max`，避免自行维护各国号段和可变长度规则。

所有身份相关操作使用规范化后的 E.164 值：

```text
OTP 摘要
OTP 限流
买家绑定唯一约束
下载阶段重新验证
会话查询
短信发送目标
脱敏展示
新生成文件的手机号水印
```

对于共享 `+1` 国家代码的号码，必须确认解析国家为加拿大，避免将美国号码误当成加拿大号码。

### 2. 改造买家输入

- 增加中国、澳大利亚、新西兰、加拿大国家选择器。
- 输入框使用 `inputMode="tel"`，接受空格、短横线、括号和可选国际前缀。
- 用户输入时按所选国家友好格式化。
- 前端提示只用于即时反馈，服务端执行最终校验。
- 国家与实际号码归属不一致时拒绝发送验证码。

### 3. 拆分短信适配器

短信层应提供统一 provider interface，并按号码国家分发：

```text
CN → Aliyun domestic SendSms
AU/NZ/CA → Aliyun international SendMessageToGlobe
```

国际短信建议采用简短英文 OTP 内容，明确品牌、验证码、有效期和禁止分享提示。Sender ID 按国家配置，不在代码中硬编码。首期可以只实现阿里云 adapter，同时保留未来增加第二供应商的接口边界。

### 4. 数据兼容与迁移

- 将现有买家绑定中的 11 位中国手机号迁移为 `+86` E.164。
- 在迁移前检查规范化后是否产生唯一约束冲突。
- 现有买家会话按绑定 ID 工作，可以保留；迁移后需验证换设备重新登录仍能匹配原绑定。
- 已成功生成的 PDF 和 ZIP 保持不变，不因手机号存储格式升级重新生成。
- 新生成文件使用完整国际格式手机号作为水印；该行为需先写入 `SPEC.md`。
- 仅有 5 分钟生命周期的旧 OTP 记录不应用于长期迁移判断，发布时需确保没有跨版本验证码验证窗口。

### 5. 稳定性与风控

- 国际短信只允许白名单国家，拒绝任意国际区号，降低高资费盗刷风险。
- 保留手机号、IP 和时间窗口限流，并评估共享校园或公寓网络导致的 IP 误伤。
- 在异常频率下要求 CAPTCHA，再设置每日硬性费用上限和告警。
- 保存脱敏号码、国家、provider、请求 ID、Message ID、提交状态、最终送达状态和延迟。
- API 返回受理成功后仍需观察运营商回执；前端为延迟送达提供清晰的重新发送倒计时。
- 不自动跨供应商重复发送同一个验证码，避免重复短信和重复计费；出现明确拒绝或确认未送达后，才允许使用新验证码走备用通道。
- 单一供应商无法保证所有海外运营商始终送达。规模增长后，应按国家准备第二短信供应商或经过业务确认的替代验证通道。

## 测试与验收清单

### 自动化测试

- 中国本地格式与 `+86` 格式归一化为相同 E.164。
- 澳大利亚、新西兰和加拿大本地格式正确归一化。
- 拒绝无效号码、固定电话、非白名单国家和国家不匹配号码。
- 拒绝选择加拿大后提交美国 `+1` 号码。
- 中国号码调用国内接口，海外号码调用国际接口。
- 国内和国际短信配置相互独立，缺少配置时返回明确的服务端配置错误。
- OTP 摘要、单次使用、失败次数、过期和限流均以 E.164 为作用域。
- 下载阶段使用本地格式重新输入时仍能匹配原 E.164 绑定。
- 手机号与订单号的双向唯一约束在迁移后继续成立。
- 脱敏展示不会泄露完整国际号码。
- PDF 和 ZIP 每页包含预期的完整国际手机号水印。
- 现有中国用户、会话、生成幂等性和下载流程无回归。
- 买家页面在窄屏和 Chrome 92 WebView 中仍可使用国家选择器和手机号输入。

### 生产验收

按国家使用专用测试号码依次完成：

5. 验证水印、重复下载和换设备重新登录。
