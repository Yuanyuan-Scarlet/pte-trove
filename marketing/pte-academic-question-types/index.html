01 QUESTION TYPE

Read Aloud

朗读文本

这题做什么

看到一段英文文本后，按原文把内容清楚、连贯地朗读出来。

题干 / 材料文本不超过 60 词
作答时间准备 30–40 秒；录音时限随题目变化
计分技能阅读 + 口语
SCORING部分得分

怎么评分

内容发音口语流利度

正确朗读原文词语可获得内容分；替换、插入或漏读会影响内容分，并分别评估发音与流利度。

作答关键

  1. 1麦克风开启后立即作答
  2. 2保持原词序，不增词漏词
  3. 3停顿、节奏和重音要自然
